# 🌹 CuttingDeep

**CuttingDeep** is a minimalist experimental game. The main challenge was to explore and implement the [Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API), pushing the limits of how players interact with the browser clipboard in a creative and meaningful way.


You can also follow the design development in figma here, all made by me -> [CuttingDeep Figma](https://www.figma.com/design/Lqez6DxgsTRoH5OJiZ67qm/CuttingDeep-Development?node-id=0-1&t=IE5SeqwNYp1RZeZD-1)
## 🧠 Concept

You are dropped into a surreal and atmospheric world with little to no guidance. The environment is suposed to guide through the game, with the minimun to no guidance.

Your main tools?  

✂️ **Cut** objects. 📋 **Paste** them somewhere else.

Every interaction is handled via the system clipboard — no hidden tricks, no local storage. What you cut or paste is actually transferred using the Clipboard API, giving the game a physical, almost tangible feel.<br>

## 💡 Motivation

While using `localStorage` or other web storage methods would have made development easier, this project was a personal challenge to learn and experiment with browser clipboard capabilities. The goal was to turn a typically background feature into a central gameplay mechanic.

## 🛠️ Technologies

- HTML5  
- CSS3  
- JavaScript  
- Clipboard API

## 🚀 How to Play

1. Dowload the files, and run it in LIVE SERVER
2. Open the game in your browser (Clipboard permissions required).
3. Explore the environment using your mouse.
4. Use **Ctrl+X**, and **Ctrl+V** to cut or paste objects.
5. Discover the rules of the world through experimentation
