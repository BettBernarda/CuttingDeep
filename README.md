# 🎮 CuttingDeep

**CuttingDeep** is a minimalist experimental game developed as a college project. The main challenge was to explore and implement the [Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API), pushing the limits of how players interact with the browser clipboard in a creative and meaningful way.

## 🧠 Concept

You are dropped into a surreal and atmospheric world with little to no guidance. The environment is mysterious, quiet, and strange.

Your main tools?  
✂️ **Cut** objects. 📋 **Paste** them somewhere else.

Every interaction is handled via the system clipboard — no hidden tricks, no local storage. What you cut or paste is actually transferred using the Clipboard API, giving the game a physical, almost tangible feel.

## 💡 Motivation

While using `localStorage` or other web storage methods would have made development easier, this project was a personal challenge to learn and experiment with browser clipboard capabilities. The goal was to turn a typically background feature into a central gameplay mechanic.

## 🛠️ Technologies

- HTML5  
- CSS3  
- JavaScript  
- Clipboard API

## 🚀 How to Play

1. Open the game in a modern browser (Chrome, Edge, Firefox – Clipboard permissions required).
2. Explore the environment using your mouse.
3. Use **Ctrl+X**, **Ctrl+C**, and **Ctrl+V** to cut, copy, or paste objects.
4. Discover the rules of the world through experimentation — there are no instructions.
